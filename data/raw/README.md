# Raw Data

Place the original downloaded OULAD CSV files in this folder.

Expected files:

- `courses.csv`
- `assessments.csv`
- `studentAssessment.csv`
- `studentInfo.csv`
- `studentRegistration.csv`
- `vle.csv`
- `studentVle.csv`

Do not modify raw files manually.

If the files are not committed to GitHub, retain this README and use the source instructions in `../README.md`.
