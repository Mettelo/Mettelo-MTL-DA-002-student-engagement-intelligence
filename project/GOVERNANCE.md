# Project Governance

## Project Classification

Mettelo Project Studio — simulated confidential-client engagement.

## Client Representation

The confidential client is simulated.

Participants must not claim:

- employment by the simulated client;
- access to a real confidential university client;
- that OULAD is private data supplied by Mettelo;
- that Mettelo has an undisclosed external client relationship represented by this project.

Participants may accurately describe verified participation in **Mettelo Project Studio**.

## Data Licence and Attribution

The underlying OULAD dataset is licensed CC BY 4.0.

Teams must retain attribution to the dataset source.

## Responsible Use

The dataset includes student characteristics and behavioural information.

Teams must:

- avoid unsupported causal claims;
- document bias and limitations;
- treat demographic analysis carefully;
- avoid presenting automated predictions as decisions;
- avoid recommendations that would unfairly deny opportunities;
- describe false-positive and false-negative consequences where early-warning models are proposed;
- protect against disclosure of personal information.

## GitHub Security

Never commit:

- passwords;
- personal access tokens;
- API keys;
- private credentials;
- personal contact details not intended for publication.

Use environment variables and `.gitignore` where appropriate.

## Verification

Mettelo may review repository history to verify participation and contribution.

Verification may consider commits, issues, pull requests, reviews, documents, analytical artefacts and final presentation contributions.
