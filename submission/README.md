# Submission & Team Repository Guidance

This folder defines how participating teams must create, structure and submit their own GitHub repositories for **MTL-DA-002**.

## Contents

- `TEAM_REPOSITORY_STANDARD.md` — mandatory team repository structure
- `SUBMISSION_GUIDE.md` — end-to-end GitHub submission process
- `FINAL_SUBMISSION_TEMPLATE.md` — template to copy into the team's own repository

The Mettelo master repository is not the team's delivery repository. Each approved team creates and submits its own repository.
